# Скрипты воркфлоу Dentify

Скрипты для инструмента Workflow (Claude Code): каждый — партия задач бэклога с циклом
«реализация → независимое ревью → исправление» по задаче, финальными ревью (приёмка,
архитектура, безопасность / UI-критик) и коммитом после каждой принятой задачи
(rules dentify R004). Агенты — `model: 'opus'`, ревью — `effort: 'xhigh'`.

| Файл | Партия | Статус |
|---|---|---|
| `phase0-backend.js` | этап 0, бэкенд (ProblemDetail/OpenAPI/i18n, тенант+RLS, безопасность, аудит, аккаунты, вход) | выполнен 2026-09-26 |
| `phase0-frontend.js` | этап 0, фронт (каркас, дизайн-система, мобильный, клиент API, i18n) | выполнен 2026-09-26 |
| `phase0-close.js` | закрытие этапа 0 (экран входа, verify одной командой, Playwright на стеке, документация) | в работе |
| `phase1-backend-a.js` | этап 1, бэкенд A (события/почта, схема clinic, права, валидаторы, search_norm, домен clinic, сид, защита входа, SMS) | ждёт |
| `phase1-backend-b.js` | этап 1, бэкенд B (S3, Excel, регистрация, владелец, контекст, аудит clinic, фабрика данных, изоляция) | ждёт |

Запуск из сессии Claude Code (ultracode): `Workflow({scriptPath: "<абсолютный путь к файлу>"})`.
Продолжение упавшего прогона — `resumeFromRunId` из вывода запуска (работает только в той же
сессии). Перед запуском: Docker Desktop запущен, `deploy/dev.ps1 up`, машина не уходит в сон.
Скрипт в файле должен быть с LF-концами строк — CRLF валидатор отвергает как «control characters».
