# Бриф: макеты экранов Dentify в стиле «Кресло»

Dentify — веб-приложение для стоматологической клиники (Казахстан): расписание, пациенты,
врачи, склад, настройки клиники, доступы. Стиль выбран: **«Кресло»** — тёмно-бирюзовый
сайдбар «лагуна», один жёлтый акцент «лампа», крупные пилюли и скругления, записи окрашены
цветом врача, мало линий. Пользователь хочет «не перегружено и понятно визуально».

Ты рисуешь статичные макеты (артборды) — по одному файлу `.dc.html` на экран. Качество как у
эталонов, стиль ровно как у эталонов. Не изобретай новых цветов, радиусов, шрифтов.

## Формат артборда (нарушение = молча не отрисуется)

Скелет — ровно как в эталонах:
```html
<!doctype html>
<html lang="ru">
<head>
<meta charset="utf-8">
<title>Короткое имя экрана</title>
<script src="./support.js"></script>
</head>
<body>
<x-dc>
<helmet>
<link href="https://fonts.googleapis.com/css2?family=Rubik:wght@500;600;700&amp;family=Nunito+Sans:wght@500;600;700;800&amp;display=swap" rel="stylesheet">
<style>
body{margin:0;background:#ECEFF3;color:#0E2230;font-family:"Nunito Sans",system-ui,sans-serif}
*{box-sizing:border-box}
button{font:inherit;color:inherit;cursor:pointer}
a{color:#0F3D4C;text-decoration:underline;text-underline-offset:3px}a:hover{color:#082A35}
:focus-visible{outline:3px solid #0F3D4C;outline-offset:2px}
</style>
</helmet>
<div style="width:1440px;height:900px; …">…весь экран…</div>
</x-dc>
<script type="text/x-dc" data-dc-script data-props='{"$preview":{"width":1440,"height":900}}'>
class Component extends DCLogic {
  renderVals() { return {}; }
}
</script>
</body>
</html>
```
- Строку `<script src="./support.js"></script>` не менять. Корневой элемент — фиксированного размера = размеру артборда (десктоп 1440×900, телефон 390×844), `$preview` тот же.
- Все стили — инлайн `style="…"` (как в эталонах). В `<helmet><style>` — только базовое из скелета.
- Закрывай каждый элемент, кавычки у всех атрибутов. Никаких `{{…}}`, `<sc-for>`, скриптов, построения DOM из JS — только статичная разметка.
- Доступность: настоящие `<button>`, `<a href>`, `<input>` + `<label for>`; у кнопок-иконок `aria-label`. Цели касания ≥ 44 px.
- Иконки — только инлайн SVG со штрихом (как в эталонах), никаких эмодзи.
- Шрифты — ТОЛЬКО Rubik (заголовки, имена, цифры) и Nunito Sans (текст). У многих шрифтов нет казахских букв ә ғ қ ң ө ұ ү һ — другие не использовать.

- Заголовок экрана: Rubik 600, 30 px. Под ним — вкладки раздела пилюлями (белый контейнер, активная вкладка — `#0E2230` + белый текст), как в `Klinika-Profil.dc.html`.
- Кнопки: жёлтая `#FFCB47` — ОДНА на экран, главное действие; второстепенная — белая с контуром 2 px `#E1E6EC`; выбранное состояние (чип, день, слот, вкладка) — заливка `#0E2230` + белый текст; отмена/удаление — красный текст `#A1231A`; подтверждение опасного действия в диалоге — красная заливка `#B42318` + белый текст.
- Поля: пилюля высотой 48, контур 2 px `#E1E6EC`, фокус — контур `#0E2230`; подпись над полем 13.5 px, 800, `#4F5B66`. Многострочное поле — радиус 20. Любой выпадающий список — с поиском (иконка лупы) и шевроном.
- Переключатель (switch): вкл — дорожка `#0E2230` 48×28, кружок `#FFCB47`; выкл — дорожка `#D5DBE2`, кружок белый.
- Статусы записи — пилюля с точкой и словом: Придёт `#3A6FD8` · Пришёл `#F2B51E` · В кресле `#16A064` · Готово (галочка, серый) · Не пришёл (белый фон + контур `#F3B9B2`, текст `#9B1C12`) · Отменена (зачёркнуто, серый).
- Цвета врачей (фон / текст / насыщенный для аватара): бирюза `#D3EEEE`/`#0B4A4F`/`#1B8A8F`, коралл `#FCE0DA`/`#7A2A1E`/`#D2503C`, сирень `#E5E1FB`/`#3D3394`/`#5B4FD1`, небо `#DDEBFB`/`#1E4F8F`/`#2F6FD1`, песок `#F6EACB`/`#6B4A0B`/`#B7791F`, роза `#F9DDEA`/`#7B1F4B`/`#B83280`.
- Предупреждение/аллергия — фон `#FDE2E0`, текст `#8A1F17`. Инфо-подсказка — блок `#F5F7F9` с иконкой «i». Активная строка списка — `#FFF4D1`.
- Много воздуха, мало рамок. Не перегружать: если не помещается — это знак убрать лишнее, а не уменьшать шрифт ниже 12.5 px.
